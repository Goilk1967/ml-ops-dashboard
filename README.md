# ML Ops Dashboard 📊

TypeScript/React dashboard for monitoring ML model performance, data drift, and inference latency in real-time.

## 🌟 Features
- **Real-time Metrics**: Live tracking of model accuracy and latency.
- **Drift Detection**: Automated alerts for data and model drift.
- **Deployment Tracking**: History of model versions and deployment statuses.

## 🚀 Development
```bash
npm install
npm start
```
